    啟用圖書館連線
    點「圖書館全文」若出現 HyProxy Login 畫面，表示這個瀏覽器還沒啟用：請關閉那一頁，按左邊按鈕完成一次登入（它會開啟 NEJM），再回來點連結。不要在 HyProxy Login 輸入帳密。
  

  
    
  
    「圖書館全文」會依館藏清單決定路線（ClinicalKey、Ovid、EBSCO 直達單篇，或解析 DOI 後經圖書館代理開啟出版社網頁）。代理的登入狀態是跟著瀏覽器走的：每台電腦、每個瀏覽器第一次使用時，按一次「啟用圖書館連線」（登入遠端系統，它會開啟 NEJM），之後連結就會直接通。「圖書館全文（出版社）」點進去若只有摘要，請改試「EBSCO 全文」或「免費版本」，再不行就用館際合作（NDDS）。帳號密碼只輸入在圖書館官方頁面，不會經過本頁。
    
  
    

  
    
    
    
      這個工具怎麼運作？帳號密碼安全嗎？
      
    
        
    資料來源有所本。每一筆結果都直接來自美國國家醫學圖書館的 PubMed 資料庫（官方 E-utilities 介面），附有 PMID 與 DOI 可供核對；本頁不會自行「產生」任何文獻。
    
        
    帳號密碼不經過本頁。本頁不會要求、也不會儲存你的圖書館帳號密碼。點「圖書館全文」會開啟圖書館官方的遠端連線系統（www.scmhem.org.tw），登入之後即可經由圖書館訂閱取得全文。
    
        
    為什麼要「啟用圖書館連線」？貴院的代理引擎是 HyProxy，它自己的登入畫面（HyProxy Login）不接受同仁的帳號密碼；正確的方式是登入 ERM 遠端系統後，由 ERM 開啟一個期刊，這時 HyProxy 才會記住這個瀏覽器已通過驗證。「啟用圖書館連線」就是替你做這件事（借用 ERM 內的 NEJM 連結）。狀態存在瀏覽器裡，所以換電腦、換瀏覽器或隔一段時間過期後，要再按一次。
    
        
    本頁不碰任何資料庫的內容。它只依 DOI、PII 或 PMID 產生連到各平台的連結，不下載、不儲存、不轉送任何資料庫內容；全文一律由 ClinicalKey、Ovid、ProQuest、EBSCO 等平台依本院的授權直接提供給你的瀏覽器，和你自己從遠端系統點進去完全相同。交給 Claude 的只有 PubMed 的公開書目與摘要，不含任何訂閱全文。
    
        
    「圖書館全文」怎麼連？圖書館的代理引擎（www.scmhem.org.tw 的 3001 埠）只代理有訂閱的出版平台，PubMed 與 doi.org 本身不在其中。本頁會先用館藏清單（holdings.csv）比對本刊訂在哪個平台再決定路線：ClinicalKey 用 PubMed 給的 PII 直達單篇、Ovid 用 DOI 直達、EBSCO MEDLINE 用 PMID 直達、ProQuest 等集成平台由 ERM 開本刊；其餘則用 doi.org 與 Crossref 的公開 API 把 DOI 解析成出版社網址，再交給代理引擎的登入入口（login?url=）處理登入與轉址，經代理後的網址長得像 www-nejm-org.www.scmhem.org.tw:3001。免費文章（PMC 或開放取用出版社）會直接開啟出版社頁面。
    
        
    為什麼有時會顯示「未訂閱」？代理引擎只認得「出版平台」，不知道圖書館在該平台上訂了哪些期刊，所以同一個網站上有的期刊能開、有的不能。若圖書館提供期刊清單（holdings.csv），本頁會用 ISSN 與刊名比對，直接標示「館藏訂閱」或「清單未列此刊」。拿不到的文章可用「免費版本」（OpenAlex／Unpaywall 找到的合法免費全文）或「館際合作」取得。
    
        
    點閱會算進院方的統計嗎？ERM 只統計經過它跳轉的點擊。所以本頁點「圖書館全文」時，會先在新分頁經 ERM 登記一次（有期刊資料就登記到該期刊，否則登記到該平台），兩三秒後再自動轉到文章；登記時 ERM 認的是你在該瀏覽器登入的帳號，所以要先「啟用圖書館連線」。免費版本、PMC、直接開 DOI 這些不經圖書館的連結，本來就不會計入。
    
        
    有些資料庫要另外登入，怎麼辦？經過圖書館代理時，大多數平台會以醫院 IP 認證，不必再輸入帳密。少數平台例外：一種是要先在院內網路註冊個人帳號（如 ClinicalKey、DynaMed），一種是圖書館提供共用帳密（如 EBSCO、Cochrane）。本頁不會存放任何帳密，遇到這些平台只會提示，並附上 ERM 資料庫簡介的連結；共用帳密只在登入 ERM 之後才看得到，請不要把它們貼到本頁或任何公開網頁。
    
        
    AI 只做兩件事。一是讀懂問題或臨床情境，歸納成 PICO 問題並轉成 PubMed 檢索式，檢索式與替代策略都完整顯示給你檢查、可自行修改；二是整理「已經查到的摘要」，每句標注來源編號。AI 不會自行提供文獻。
    
        
    AI 是誰提供的？是圖書館自己架的「AI 中繼站」，就跑在本站同一個網域上（Cloudflare 免費方案），用 Cloudflare Workers AI 執行。同仁不需要任何 AI 帳號，也不必登入。送出去的只有你打的問題，以及 PubMed 的公開書目與摘要；Cloudflare 明文承諾不會把客戶內容用於訓練模型，中繼站本身也不保存查詢內容（只記錄每日用量數字）。請不要輸入病人可識別資料。額度用完時（每天早上 8 點重置），查詢與全文連結完全不受影響，只有「重點整理」會改成由你自己的 Claude 帳號處理。
    
        
    AI 用誰的帳號？目前這個頁面沒有接上圖書館的 AI 中繼站，所以本頁不含任何 AI。按「請 Claude 轉成檢索式」或「交給你的 Claude 整理重點」時，會開啟你自己的 Claude（claude.ai，免費帳號即可）並把指令帶進輸入框，由你按送出；Claude 只會拿到你輸入的問題和 PubMed 的公開摘要。第一步 Claude 會回覆「找文獻」的連結，點了就回到本頁自動查 PubMed，所以每一筆文獻仍然是資料庫查出來的，不是 AI 憑空產生的。沒有 Claude 帳號的同仁也可以直接用英文關鍵詞查詢。
    
        
    要讓全院同仁使用？把這一個 HTML 檔（連同 holdings.csv）放到院內網站或任何靜態網頁空間（例如 GitHub Pages）即可，不需要伺服器程式、不需要任何付費服務；直接用瀏覽器開啟檔案也能查詢，只是「請 Claude 轉成檢索式」的回程連結需要放在網站上才有效。
    
        
    找不到想要的內容？華藝中文期刊、UpToDate、ClinicalKey、Micromedex 等資料庫不在 PubMed 索引範圍，請從圖書館遠端系統的資料庫清單進入查詢。

          館藏期刊清單（用來標示「有沒有訂閱」）
          
    把 ERM 匯出的電子期刊清單存成 CSV（UTF-8），檔名 holdings.csv，放在與 index.html 同一個資料夾，本頁會自動載入。標題列請用 title, issn, eissn, from, to, note，欄位可以缺少，也接受中文標題列。用擷取腳本從 ERM 抓下來的 erm-journals.csv（欄位 journal_id, title, issn, lang, years, database）可以直接改名為 holdings.csv 使用：有 journal_id 時，集成平台（OVID、ProQuest、ClinicalKey…）的期刊會改由 ERM 開啟本刊。
    
          
          
    
        
    
        
        
    
          AI 中繼站
          
    檢查中…
    
          
    中繼站就是同一個網站裡的 _worker.js（Cloudflare Pages）。要讓它運作，只需在 Pages 專案的 Settings → Bindings → Add → Workers AI，變數名稱填 AI，再重新部署一次。狀態頁在 /api/ai。中繼站不在時，頁面會自動改用「交棒」模式，查詢與全文都不受影響。
    
          
        
    
        
        
        
        
        
        
        
        
    這些設定只在本次開啟期間有效。要永久變更，請編輯檔案開頭的 CONFIG 區塊。
